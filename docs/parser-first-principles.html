00安全的三个阶

先把「安全」这件事本身分层。同一个 bug，在三个阶上的命运完全不同。

阶一 · 劝告

约定并上报

「每个丢弃的分支都要记得 pushDiag。」
后果：内容被算法结构吃掉时，没有任何分支觉得自己丢了东西 → 诊断数为 0。

阶二 · 侦测

事后校验覆盖率

「流水线末端加审计器，不平账就报。」
后果：能抓住 bug，但审计器是独立组件，理论上可与流水线漂移；且是事后。

阶三 · 不可表达

让不安全的操作不存在

「语言里没有 filter，只有 partition。」
后果：不是「会被抓到」，而是根本构造不出一个丢内容的覆盖。

↑ 我们目前停在阶一；上一版提议到了阶二；本报告主张直接到阶三。

类比最清楚：类型系统不会去「检查」null——它让 null 不成为合法值。我们要的是同一次跃迁：从运行时检查，到构造期禁止。

01五条公理

不是五个模块，是五条不可违背的公理。架构是从它们推导出来的，而不是拼出来的。

0
Invariant Substrate

不可变基底

源文档永不改变、永不被消费、永不被切碎。所有解析产物都是对它的指涉（reference），而非拷贝。

推论：不存在「拷贝环节」，因此内容不可能在拷贝时丢失。你只能「没有指到它」——而那是可测量的覆盖问题。
1
The Covering Law · 全域律

解析的产物是一个「覆盖」

解析不产出「提取出的内容」，而产出一个 Covering（覆盖）：一组带标签的区域，其并集 ≡ 全文。

这是构造约束，不是运行时检查：唯一的构造方式是全域分区（total partition）——每个输入原子必须落入恰好一个桶。语言里没有 filter，只有 partition。

推论：「丢弃」不是删除，而是把区域标记为 waste(reason)——它仍在覆盖中，只是不被投影。于是「内容消失」在代数上不可表达。
2
Dual Projection

输出与审计是同一对象的两次投影

「笔记输出」与「审计报告／覆盖率」都是同一个 Covering 的投影。

推论：二者不可能互相说谎。这直接消灭了上一版里「审计器可能与流水线漂移」的隐患——不是靠纪律，是靠同源。
3
Alignment as Sequence Alignment

对齐是序列对齐，不是 id 查找

目录与正文是两条序列。对齐应当是保序的全局最优匹配（Needleman-Wunsch 式动态规划），而非「逐个 id 查表、查不到就放弃」。

评分可由多重证据合成：精确id ＞ 归一化id ＞ 标题文本相似 ＞ 位置先验。

推论：即使 id 全部缺失（资治通鉴 290 章一个 id 都没有），标题文本 + 顺序仍是极强的信号——结构依然可恢复，而不是塌成一个整文件。
4
Confidence Algebra

置信度是一等公民且可组合

每个断言携带置信度，且在组合下封闭（合取取 min，串行相乘）。

推论：系统永不把猜测呈现为事实。L2/L3 这类「猜」出来的对齐，天生带着较低的置信度，无法伪装成精确命中。

05框架全貌

五条公理落到形状上。注意：这里没有独立的审计组件——审计就是右侧那条投影。

06为什么这次是彻底的

上一版的三条原则（守恒／协商／溯源）曾是我的主张；在这一版里，它们降格为推论——这正是「更根本」的标志。

上一版（主张）本版（地位）由何推导
守恒：加审计器校验覆盖率推论，且更强公理 1 全域律 + 公理 2 双投影（审计=投影，非组件）
协商：L0–L4 降级阶梯推论，且更优公理 3：阶梯是逐步试探；序列对齐是全局最优，且 id 缺失时仍能恢复
溯源：每单元携带来源坐标推论，且免费公理 0：产物本就是「指涉」，坐标是指涉自带的，无需额外机制
（无）置信度代数公理 4：新增——让「猜」无法伪装成「知」

判断标准很简单：如果一个原则需要单独的组件去实现，它就还不够根本；如果它从公理里自然长出来，它才是根本的。

07代价、风险与可证伪判据

诚实标价。这套框架不是免费的。

  • 概念成本最高：从「提取」转向「覆盖 + 投影」，是一次
    心智模型更换，团队需要重新训练直觉。
  • 内存：基底需常驻到覆盖构造完成，超大书有峰值压力（可按文件作用域释放缓解）。
  • 序列对齐是启发式的：文本相似 + 保序可能错配。缓解不是消除——而是公理 4 强制它带着低置信度呈现，绝不冒充精确。
  • 收益仍不均：规整的书（TheEconomist，0 受影响文件）几乎零收益；价值集中在畸形／古老／工具生成的 EPUB——而那正是最需要安全的场景。
  • 性能不是障碍：11MB / 290 章实测 2.1 秒，DP 对齐与覆盖构造完全放得下。

可证伪判据

对任意输入：覆盖的并集 ≡ 全文（覆盖率 100%，或给出带理由的 waste 清单）；

每个目录条目在对齐矩阵中有且仅有一个匹配（含显式 unmatched + 原因）；

每个断言必须携带置信度，缺失置信度视为类型错误；

输出与报告由同一个覆盖投影而来——若二者可能不一致，则实现违背了公理 2。

这四条可机器校验。任何一条不成立，框架即被证伪。
